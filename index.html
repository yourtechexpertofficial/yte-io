YTE Icons

A hand-drawn interface icon library, built for Cosvire products and released for anyone to use. Every glyph is drawn on the same grid with matching stroke weights, so the set stays visually consistent at any size.

It ships as a webfont in four formats with a CSS class per icon — drop in one stylesheet and the whole set is available.

Documentation

Two lines to install.

Link the stylesheet, then reference any icon by its class. The font loads once and every glyph in the set becomes available — no build step, no JavaScript, no package manager required.

Icons inherit color and font-size from their parent, so they scale and theme with the rest of your interface.

index.html 
<!-- 1. Load the stylesheet -->
<link rel="stylesheet" href="style.css">

<!-- 2. Use any icon -->
<i class="ico-user"></i>
<i class="ico-search"></i>
<i class="ico-settings"></i>
